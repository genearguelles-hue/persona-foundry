# Persona Foundry

Persona Foundry is an iOS prototype for creating, saving, exporting, and running structured AI personas as part of a broader Persona Engineering workflow.

The app supports persona construction using:

- Missions
- Persona axioms
- Persona primitives
- Engram schemas
- Persona specifications
- JSON export
- Backend-assisted persona-governed generation

## Current Capabilities

- Generate structured persona specifications
- Save personas locally on device
- Export persona specifications as JSON
- Import exported personas into a local Persona Domain environment
- Run saved personas through a configured backend generation layer
- Display validation notes tied to persona constraints
