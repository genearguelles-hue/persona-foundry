# Persona Foundry Beta Testing Instructions

Persona Foundry is an early iOS prototype for creating, saving, exporting, and running structured AI personas.

## What to Test

Please test the following workflow:

1. Complete onboarding and AI/privacy acknowledgement.
2. Create a new persona.
3. Select a mission type and enter a mission description.
4. Tune persona primitives.
5. Select optional axioms.
6. Select allowed and forbidden engram types.
7. Generate and save the persona.
8. Open My Personas and inspect the saved persona card.
9. Export the persona as a JSON file.
10. Configure the backend URL in Settings if backend access is provided.
11. Run the saved persona and generate a draft.
12. Review the generated draft and validation notes.
13. Test copy, share, regenerate, and clear actions.

## Please Report Issues With

- Confusing wording
- Broken navigation
- Persona generation quality
- Saving or deleting personas
- JSON export
- Backend connection
- Generated draft quality
- Validation notes
- Visual layout problems
- Crashes or freezes

## Safety and Privacy Notice

Do not enter sensitive personal, medical, financial, legal, confidential, or emergency information during testing.

Generated content may be inaccurate, incomplete, or inappropriate for some uses. Review all generated content before relying on it or sharing it.

Persona Foundry is not medical, mental health, legal, financial, or professional advice.
