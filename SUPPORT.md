# Persona Foundry Support

genearguelles@me.com

## Beta Feedback

When reporting an issue, please include:

- Device model
- iOS version
- App version
- Description of the issue
- Steps to reproduce
- Screenshots, if helpful

## Known Beta Areas

Persona Foundry is currently in beta preparation. The following areas are especially useful to test:

- Persona creation flow
- Persona saving and deletion
- JSON export
- Backend URL configuration
- Persona runtime generation
- Generated draft quality
- Validation notes
- App navigation and visual clarity

## Important Notice

Persona Foundry is an AI design and prototyping tool. It is not medical, mental health, legal, financial, or professional advice.

Do not use Persona Foundry for emergencies, crisis support, diagnosis, treatment, or high-stakes decisions.
